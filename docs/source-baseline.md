# Website source baseline

The aidecis-website repository is a separate home for the public marketing website at www.aidecis.com. It is independent of the aidecis-app, aidecis-crm-csm, and LIBI repositories.

The public static website was fetched read-only from https://www.aidecis.com/ on 17 October 2026 to establish a version-controlled baseline. At capture, the homepage response reported Last-Modified: 10 October 2026. The source snapshot includes the home page, benefits calculator, industries, legal pages, contact page, public demo entrypoints, and referenced same-origin assets. The local archive named aidecis-website-v10.2.zip had a README describing itself as v9.14 and did not contain the full set of currently published pages; it was therefore not treated as authoritative source.

This repository is the source and review workflow for the public website. The current branch contains the proposed 2026 transformation, not a production deployment. Production publication remains a deliberate, manual step after pull-request review.
